# Pickel

Pickel is a local-first, controlled, observable, and extensible Agent Runtime.

## Documentation

The Chinese [README](README.md) is the canonical documentation entry point. Its [documentation index](README.md#文档入口) identifies the six current Runtime contracts and explains how older design notes are scoped.

This English page intentionally does not duplicate the Runtime contracts. The older English feature descriptions and command examples were removed because they referred to superseded configuration, persistence, and execution terminology.

For project setup and commands, follow the repository configuration and the current documentation linked from the canonical index.
